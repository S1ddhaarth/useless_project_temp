Kozhikkuttan 🐣

A robot with too much personality — high-fives women, flips off men.

🤖 What is this?

Kozhikkuttan uses real-time gender detection (DeepFace + OpenCV) to decide whether to greet you with a high-five or a middle finger, powered by an ESP32 and a servo motor. Because machines deserve opinions too.

🛠️ Built with

  • Python & OpenCV — computer vision pipeline
  • DeepFace — gender classification
  • ESP32 + Servo SG90 — the physical sass
  • Arduino IDE & C++ — firmware
